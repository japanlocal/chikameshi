# ちかめし 🍽️

GPSで現在地を取得し、**人数・空気感・食べたいもの・予算** から近くのおすすめ飲食店を表示するWebアプリです。

**公開URL: https://japanlocal.github.io/chikameshi/** （スマホで開いてホーム画面に追加できます）

## 主な機能

- 📍 GPSで現在地を取得（地図タップで場所の指定も可）
- 👥✨🍜💴 人数・空気感・食べたいもの・予算から、おすすめ順に表示
- ↕️ おすすめ順 / 近い順 / 安い順 の並び替え
- 🎲 迷ったらおまかせ（上位5軒からルーレットで1軒を決める）
- ❤️ お気に入り（下のタブからいつでも見られる。端末内に保存）
- 📤 共有（LINEなどへ送る。共有メニューがない環境ではコピー）
- 💾 前回の検索条件を記憶
- 📲 ホーム画面に追加・オフライン起動（PWA）

## 起動方法

```sh
cd アプリ開発
python3 -m http.server 8765
```

ブラウザで http://localhost:8765 を開きます。
（位置情報は `https` か `localhost` でしか使えないため、ファイルを直接開く方法では動きません）

スマホで使う場合は、GitHub Pages / Netlify / Vercel などの https 環境に置いてください。ビルドは不要です。

## ホーム画面に追加 (PWA)

https で公開したURLをスマホで開き、次の手順でホーム画面に追加するとアプリとして起動できます。

- **iPhone (Safari)**: 共有ボタン（□↑）→「ホーム画面に追加」（画面上部にも案内が出ます）
- **Android (Chrome)**: 画面右上の「📲 インストール」ボタン、またはメニュー →「アプリをインストール」

一度開いたあとはオフラインでも起動します（お店の検索には通信が必要です）。
アプリのファイルを更新したら、`sw.js` の `VERSION` を上げてください。古いキャッシュが入れ替わります。

## 店舗データ

| データ元 | 設定 | 特徴 |
|---|---|---|
| ホットペッパーグルメAPI | ⚙️ からAPIキーを入力 | 予算・個室・飲み放題・収容人数・写真まで使って精度高く絞り込める |
| OpenStreetMap (Overpass API) | 設定不要 | キーなしで動く。予算は業態からの推定値 |

APIキーは https://webservice.recruit.co.jp/register/ で無料取得できます。キーはブラウザの localStorage に保存されます。

## おすすめ順の決め方 (app.js の `scoreShop`)

- **食べたいもの**: 選んだジャンルに合わない店は除外
- **人数**: 収容人数が足りない店は除外。6人以上なら個室・貸切可を加点、カフェ・ファストフードは減点
- **予算**: 予算オーバーの店は除外（OSMの推定値の場合は減点のみ）
- **空気感**: ジャンルと設備（個室・飲み放題・禁煙・子連れOKなど）の組み合わせで加点
- **距離**: 近いほど加点

空気感ごとの重み付けは `data.js` の `VIBES` で調整できます。

## ファイル構成

- `index.html` … 画面
- `style.css` … 見た目（ダークモード対応）
- `data.js` … 選択肢と各データソースへの対応表
- `sources.js` … ホットペッパー / OpenStreetMap からの取得と正規化
- `app.js` … 画面制御・地図・スコアリング・インストール案内
- `manifest.webmanifest` … アプリ名・アイコンなど PWA の定義
- `sw.js` … Service Worker（オフライン起動・地図タイルのキャッシュ）
- `icons/` … アプリアイコン（`icon.svg` が元データ）
